altWinDirStat 2.1.0 adds **folder ledgers**: save a snapshot of a scan's folders as a baseline, then compare it side by side with a later scan to see what changed. It's based on WinDirStat 2.8.8.

> Unofficial fork of [WinDirStat](https://github.com/windirstat/windirstat), not affiliated with the WinDirStat team.

## New: folder ledger and baseline comparison

- **File → Export Folder Ledger...** saves a small `.ledger.csv`.
  - It has one row per folder, with the folder's total size, file count and subfolder count. There are no per-file rows.
  - It opens in Excel.
- **File → Compare with Folder Ledger...** compares a baseline ledger with the scan that's open. If no scan is open, it asks for a second ledger.
  - **Side by side:** each folder shows its baseline and current size and file count, and the change in each.
  - **Colour-coded:** folders are marked **Added**, **Removed**, **Grown**, **Shrunk** or **Files changed**.
  - **Summary:** the count of each change type, and the net size and file change.
  - **Tools:** a text filter, a **Show unchanged folders** option, sorting by any column, **Export Comparison...** to CSV, and double-click to open a folder in Explorer.
- **Matching:** folders are matched by path relative to the scan root, ignoring case.
  - A baseline of `C:\Data` compared with a scan of all of `C:` is narrowed to `C:\Data` automatically.
  - A copy on another drive is matched folder by folder.
- **Scheduled baselines:** a Save Results or `/saveto` target ending in `.ledger.csv` writes a ledger, so a scheduled task can record baselines:

  ```
  altWinDirStat.exe /saveto "D:\Baselines\data.ledger.csv" "D:\Data"
  ```

## Verified in CI

- **Folder ledger:** a ledger of a 700,001-file test tree has exactly 6,324 folder rows (571 KB), written in 0.7 s, and its root totals match the tree exactly.
- **Large-scan stress test:**
  - The 700k-file tree scanned in about 1 s, with a worst UI response of 1 ms.
  - A full `C:\` scan took 18 s, with a worst UI response of 0.2 s.
- **Upstream test suites:** 916 checks passed on x64 and Win32.

## Known limitations

- **Unsigned.** SmartScreen warns on first run (**More info → Run anyway**), and Windows 11 **Smart App Control blocks it** where it's turned on.
- **Ledger strings are English-only** for now. The rest of the interface keeps its translations.
