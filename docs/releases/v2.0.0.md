First altWinDirStat release built on the official **WinDirStat 2.x** code (based on WinDirStat 2.8.8). It replaces the legacy 1.x codebase, which scanned on the UI thread and could look hung on large drives.

> Unofficial fork of [WinDirStat](https://github.com/windirstat/windirstat), not affiliated with the WinDirStat team. For the official, signed app, use the [official WinDirStat releases](https://github.com/windirstat/windirstat/releases).

## Downloads

| File | Use |
|---|---|
| `altWinDirStat-2.0.0-x64-Setup.exe` | **Recommended.** Per-user (no admin) or all-users install, with an optional "Analyze with altWinDirStat" Explorer right-click entry. |
| `altWinDirStat-2.0.0-x64-portable.zip` | A single `altWinDirStat.exe`: unzip and run. Good for servers. |
| `altWinDirStat-2.0.0-{ARM64,Win32}-*` | The same builds for ARM64 and 32-bit Windows. |
| `SHA256SUMS.txt` | Checksums for every file above (`Get-FileHash <file> -Algorithm SHA256`). |

## What's new since 1.0.0

- **Scans no longer freeze the window.** Scanning runs on worker threads; with administrator rights it reads the NTFS MFT directly.
- **Suspend, resume and stop** a scan in progress.
- **New views:** All Files, Largest Files, Duplicate Files (by hash), Search Results (filters and regular expressions), File Watcher.
- **Cleanup shortcuts:** Disk Cleanup, DISM, shadow copies, CHKDSK and user-defined cleanups.
- Dark mode, high-DPI support and localization.

## Upgrading from 1.0.0

The installer upgrades a 1.0.0 install in place: same install ID, same `altWinDirStat.exe` name, same Explorer right-click entry. The portable build can simply replace the old exe.

## Known limitations

- **Unsigned.** SmartScreen warns on first run (**More info → Run anyway**), and Windows 11 **Smart App Control blocks it** where it's turned on.
- Help → manual and website links go to windirstat.net, the upstream documentation.
- Server Core has no desktop shell, so use a server with Desktop Experience.
