First stable release of the altWinDirStat revival: a native Windows disk-usage viewer (a fork of WinDirStat) that works on modern Windows **and Windows Server**.

## Downloads

| File | Use |
|---|---|
| `altWinDirStat-1.0.0-x64-Setup.exe` | **Recommended.** Installs per-user (no admin) or for all users. Adds a Start Menu shortcut and an uninstaller, plus optional desktop and Explorer right-click entries. |
| `altWinDirStat-1.0.0-x64-portable.zip` | Single self-contained `.exe`; unzip and run. Good for servers. |
| `altWinDirStat-1.0.0-Win32-*` | The same builds for 32-bit Windows. |
| `SHA256SUMS.txt` | Checksums for every file above. |
| `*.png` | CI screenshots taken on Windows Server 2022 while the build was tested. |

The installer and the exe aren't code-signed yet, so SmartScreen will warn on first run: choose **More info → Run anyway**.

## Highlights

**New features**
- **Windows Server support.** There's no .NET or VC++ redistributable to install: MFC and the CRT are linked statically into the exe. It needs no admin rights to scan; folders you can't read are skipped.
- **Explorer right-click menu:** "Analyze with altWinDirStat" on folders and drives.
- **Cleanup actions** in the tree and treemap right-click menus:
  - Delete to Recycle Bin (Del)
  - Permanent delete (Shift+Del)
  - Explorer Here (Ctrl+E)
  - Command Prompt Here (Ctrl+P)
  - Copy Path (Ctrl+C)
- **Refresh (F5)** rescans the current folder or drive.
- **Version info.** Help → About and the exe's file properties both show the version.

**Fixes**
- The app no longer crashes on first launch when started with a path, which is what the Explorer context menu does.
- The app no longer crashes after a Delete or Refresh, or while the treemap redraws during a rescan.
- The app used to exit on many recoverable scan and input conditions; it now skips the item and carries on.

**Settings**
- Settings now live in `HKCU\Software\altWinDirStat`. Older settings are copied over once on first launch.

## Verified in CI
Tested on Windows Server 2022 Datacenter (build 20348), x64 and Win32:
- Scanned `C:\Program Files` (60.3 GB, 303k items, about 2 minutes) with the treemap rendered.
- Ran 5 Refresh rescans without problems.
- Migrated settings from the old registry key.
- Silently installed and uninstalled, with the context-menu entry registered.

## Known limitations
- The window stops responding while a scan runs and fills in when it finishes, so a very large drive can look hung for a minute or two.
- Delete uses `SHFileOperation`, so it can't delete paths longer than 260 characters (MAX_PATH).
- Server Core has no desktop shell, so you need a server with Desktop Experience.
