Maintenance release of altWinDirStat (based on WinDirStat 2.8.8).

> Unofficial fork of [WinDirStat](https://github.com/windirstat/windirstat), not affiliated with the WinDirStat team.

## Downloads

| File | Use |
|---|---|
| `altWinDirStat-2.0.1-x64-Setup.exe` | **Recommended.** Per-user (no admin) or all-users install. It upgrades 1.x or 2.0.0 in place. |
| `altWinDirStat-2.0.1-x64-portable.zip` | A single `altWinDirStat.exe`: unzip and run. |
| `altWinDirStat-2.0.1-{ARM64,Win32}-*` | The same builds for ARM64 and 32-bit Windows. |
| `SHA256SUMS.txt` | Checksums for every file above. |

## Changes since 2.0.0

- **Help → Report Bug** now opens this project's issue tracker instead of the official WinDirStat one.
- **Settings → Cleanups:** the ↑/↓ buttons line up with the list again (fix ported from upstream).

## Verified in CI

- **Large-scan stress test:**
  - A 700,001-file tree, including a single folder with 100,000 files and a path deeper than MAX_PATH, scanned in about 1 s. The export matched every file and the exact byte total.
  - A full `C:\` scan using the NTFS MFT engine took 18 s.
  - The window's slowest response during those scans was 0.4 s. Windows marks a window "Not Responding" at 5 s.
- **Upstream test suites:** 916 checks passed on x64 and Win32, across the Filtering, CLI, Edge Cases, Permissions, Enumeration, UNC and UI suites.

## Known limitations

- **Unsigned.** SmartScreen warns on first run (**More info → Run anyway**), and Windows 11 **Smart App Control blocks it** where it's turned on.
